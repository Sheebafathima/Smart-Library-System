# Smart Library Management System

A modern and responsive Library Management System built using React, Node.js, Express, and MongoDB. This project helps librarians and students manage books, issue/return records, user accounts, and fines efficiently through a clean and user-friendly interface.

---

# Features

## Authentication
- Admin Login
- Student Login
- Secure Authentication
- Protected Routes

## Dashboard
- Total Books Count
- Issued Books Statistics
- Returned Books Statistics
- Active Users Overview

## Book Management
- Add New Books
- Edit Book Details
- Delete Books
- Search Books
- Filter Books
- Upload Book Covers

## Issue & Return System
- Issue Books to Students
- Return Books
- Track Due Dates
- Automatic Fine Calculation

## User Management
- Add Students
- Manage Users
- View Borrowing History

## UI Features
- Responsive Design
- Modern Dashboard
- Sidebar Navigation
- Dark/Light Mode
- Interactive Tables and Cards
